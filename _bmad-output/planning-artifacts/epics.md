# Épicos - Whitebox

## EPIC-01: Motor de Telemetria Comportamental & Cliente
**Objetivo**: Construir a base para rastrear como os alunos interagem com o documento.
- **Recursos**: Timers de foco ativo, detecção de eventos de colagem, rastreamento de delta de contagem de palavras e gatilhos `onEdit`.

## EPIC-02: IA Socrática & Camada de Proxy
**Objetivo**: Implementar o "Cérebro" do sistema usando IA generativa.
- **Recursos**: Integração com API Gemini, resolução de chaves hierárquicas, engenharia de prompts socráticos e detecção de mudança de tom.

## EPIC-03: Hardening de Segurança & Integridade
**Objetivo**: Proteger o sistema contra abusos e garantir a integridade dos dados.
- **Recursos**: Autenticação `SHARED_TOKEN`, limite de taxa (rate limiting), marca d'água anti-LLM de largura zero e gestão de versão de esquema.

## EPIC-04: Integração com Ecossistema Educacional
**Objetivo**: Integrar-se perfeitamente ao fluxo de trabalho do professor.
- **Recursos**: Integração com API do Google Classroom, distribuição automatizada de "Doc Mestre" e mapeamento de tarefa para log.

## EPIC-05: Inteligência Administrativa
**Objetivo**: Fornecer visão panorâmica e ferramentas de gestão.
- **Recursos**: Painel Admin Global, Onboarding de Professores (Forms), Licenciamento B2B e Mapas de Calor Hierárquicos.
