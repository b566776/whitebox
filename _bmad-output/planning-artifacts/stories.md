# Histórias de Usuário - Whitebox

## EPIC-01: Telemetria Comportamental
- **STORY-01.1**: Como professor, quero ver quantos minutos um aluno passou digitando ativamente, para que eu possa avaliar seu esforço.
- **STORY-01.2**: Como professor, quero ser alertado se um aluno colar um grande bloco de texto, para que eu possa investigar um potencial plágio.
- **STORY-01.3**: Como sistema, preciso coletar telemetria mesmo quando o aluno estiver offline (sincronizando mais tarde), para garantir a continuidade dos dados.

## EPIC-02: IA Socrática
- **STORY-02.1**: Como aluno, quero receber perguntas socráticas sobre minha escrita, para que eu possa melhorar meu pensamento crítico.
- **STORY-02.2**: Como professor, quero configurar o "rigor" da análise da IA para cada tarefa, para corresponder ao nível da turma.
- **STORY-02.3**: Como professor, quero usar minha própria chave de API Gemini com segurança, para não depender de cotas institucionais.

## EPIC-03: Segurança & Hardening
- **STORY-03.1**: Como admin, quero rotacionar o `SHARED_TOKEN` regularmente, para manter a segurança do sistema.
- **STORY-03.2**: Como professor, quero evitar que os alunos simplesmente copiem meu prompt no ChatGPT, por isso uso marcas d'água invisíveis.
- **STORY-03.3**: Como sistema, preciso migrar esquemas de planilhas automaticamente quando novos recursos forem adicionados, para evitar corrupção de dados.

## EPIC-04: Integração com Ecossistema
- **STORY-04.1**: Como professor, quero publicar um documento "ativado com Whitebox" no meu curso do Classroom, para que os alunos possam começar a escrever imediatamente.
- **STORY-04.2**: Como professor, quero que os logs dos alunos sejam categorizados automaticamente por Tarefa do Classroom, para economizar tempo na organização.

## EPIC-05: Inteligência Administrativa
- **STORY-05.1**: Como admin, quero ver um mapa de calor da integridade dos alunos em toda a escola, para identificar turmas em risco.
- **STORY-05.2**: Como professor, quero um formulário simples para me registrar no sistema, para que eu possa começar a usar o Whitebox sem configuração manual.
- **STORY-05.3**: Como admin, quero ativar ou desativar licenças de professores instantaneamente, para gerenciar assinaturas B2B.
