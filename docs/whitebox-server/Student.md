# Whitebox Server - Dados & Privacidade do Aluno

O Whitebox é projetado com princípios de "Privacidade por Design", garantindo que seu processo de escrita seja auditado de forma segura e ética.

## 🔒 Isolamento de Dados
- **Sem Banco de Dados Global**: Suas métricas detalhadas de digitação e telemetria comportamental não são armazenadas em um banco de dados central gigante.
- **Cofres Isolados**: Seus logs são enviados diretamente para a planilha privada do seu professor, isolada de outros professores e instituições.

## 📡 Comunicação Segura
- **Handshake Criptografado**: Todos os dados enviados do seu documento para o servidor são criptografados via HTTPS.
- **Autorização por Token**: Apenas documentos autorizados (do "Modelo Mestre" do seu professor) podem se comunicar com o servidor.

## 🕵️ Auditoria Comportamental (Não Vigilância)
O servidor não grava cada tecla digitada ou sua identidade pessoal fora do domínio escolar. Ele foca em:
- **Tendências Métricas**: Tempo gasto, ritmo de edição e mudanças estruturais.
- **Feedback de IA**: O servidor processa seu texto para fornecer perguntas socráticas, ajudando você a demonstrar a originalidade de suas ideias.
